# P1 部署与域名方案

## 结论

当前项目是纯静态 HTML/CSS/JS，不需要 EdgeOne，也不需要服务器端程序。P1.6已使用CloudBase平台子域名的独立子路径公开部署，后续仍可直接迁移到其他静态托管平台或绑定自有域名。

当前地址：<https://hanako-d1gka3sb1da03c66b-1327318533.tcloudbaseapp.com/humanities-courses/>

永久网址不等于必须注册域名：

- GitHub Pages：提供 `用户名.github.io` 或 `用户名.github.io/仓库名`。
- Cloudflare Pages：提供 `项目名.pages.dev`。
- Netlify：提供 `项目名.netlify.app`。

这些地址可以长期使用，但归平台账号所有，平台规则、账号状态和网络可达性会影响它们。自有域名需要注册，通常按年续费；它只是地址所有权，仍需把 DNS 指向托管平台。换平台时只改 DNS，用户地址可以保持不变。

## 本项目推荐顺序

### 试用阶段：先用本地或平台临时地址

运行：

```bash
npm run build:site
```

产物在 `dist/`，只含：

- `index.html`
- `data/courses.js`
- `data/paths.js`
- `_headers`
- `_redirects`
- `robots.txt`
- `.nojekyll`

`dist/` 不含 `courses.json`、`.edgeone`、报告、巡检工具、封面和凭证。

### 当前公开试用：CloudBase独立子路径

P1.6只上传 `dist/` 到CloudBase共享环境的 `/humanities-courses/`，未覆盖根站神话学游戏。CloudBase CLI上传7个文件全部成功，公网桌面、390px移动端、实际课程点击与核心资源哈希均通过。

CloudBase未解析项目中的通用 `_headers` 文件。页面已使用meta提供CSP和Referrer Policy；`X-Content-Type-Options`、Permissions Policy与防嵌入策略仍需平台级响应头配置。中国大陆不同地区与不同运营商的实际稳定性仍需三网测试。

### 备选迁移：Cloudflare Pages / Netlify / GitHub Pages三选一

| 平台 | 平台地址 | 适合情况 | 主要顾虑 |
|---|---|---|---|
| GitHub Pages | `*.github.io` | 已有 GitHub，想要最简单的版本发布 | 中国大陆访问速度和可达性需要实测；仓库发布通常需要公开 |
| Cloudflare Pages | `*.pages.dev` | 想要静态托管、预览和自动部署 | 中国大陆访问不可一概保证；平台仍可能有地区/网络波动 |
| Netlify | `*.netlify.app` | 想拖拽部署或使用 Git 自动部署 | 中国大陆访问需要实测；平台子域名仍属于 Netlify |

官方文档均确认平台会提供默认子域名；自定义域名属于可选项。当前不建议继续使用 EdgeOne，除非之后明确确认其访问策略和凭证治理满足要求。

### 中国大陆用户为主

海外静态托管平台没有一个可以仅凭平台名称保证大陆三网稳定访问。Cloudflare Pages、GitHub Pages、Netlify 都应先用真实网络测试：电信、联通、移动，桌面浏览器和手机网络各测一次。

如果后续确认用户主要在大陆且需要稳定公开访问，应评估：

1. 中国大陆云厂商静态网站托管或对象存储 + CDN；
2. 备案主体、域名备案和网站备案要求；
3. 香港静态主机或对象存储作为不备案的折中方案；
4. 国内外双站点或按网络环境分流。

备案与平台政策属于当前事实，正式购买前要按实际云厂商和域名注册商规则重新确认。

## 自有域名是否值得现在买

暂时不必立即买。项目当前仍在首轮课程人工核验阶段，先用平台子域名完成 15～24 人试用更合理。满足以下条件后再注册：

- 20 门核心课程中已有可发布的一组；
- 至少一条路径完成教师复核；
- 15～24 人试用确认有人实际完成第一节点；
- 明确项目名称和长期维护者；
- 已选定托管平台并完成一次迁移演练。

注册域名时优先选择短、易读、与项目定位相关的英文域名；中文域名可以作为品牌保护，不建议作为唯一入口。

## 安全边界

- 不把任何部署 Token 写入代码、ZIP、`dist/` 或聊天。
- GitHub/Cloudflare/Netlify 只授权指定仓库，不给全账号无关权限。
- 预览地址不要放未核验课程的敏感信息。
- EdgeOne 原 Token 仍需在控制台吊销；改用别的平台不能自动吊销旧凭证。
