## 一、项目形态（30 秒理解）

- 纯静态站点：无后端、无数据库、无用户体系、**零 npm 依赖**（tools/ 仅用 Node 内置模块）。
- `index.html` 单文件应用（约 3177 行：994 行 CSS + 1978 行内联 JS + 21 个描边 SVG 图标键）；数据经 `data/courses.js`、`data/paths.js` 以 `window` 全局变量加载（由 `data/*.json` 确定性生成，支持 `file://` 直开）。
- 工具链：Node ≥22 的 14 个脚本（tools/），自研门禁链（Schema/业务规则/WCAG 对比度/符号字形/账本闭合/离线联网巡检/二轮审计 20 项），自研 CDP 浏览器回归（无 Puppeteer）。
- 历史部署 CloudBase 测试域名；canonical 当前指向该测试域名，正式域名未定。

## 四、已知雷区（先读再动手）

1. **数据单一编辑源**：只编辑 `data/courses.json` 与 `data/paths.json`；`courses.js/paths.js` 是生成物，改 JSON 后必须 `node tools/build-data-script.js`（`--check` 做字节级漂移比对，实测注入 1 字节即被拦截，重建字节级确定）。
2. **迁移熔断**：`tools/migrate-p1-data.js` 与 `tools/apply-source-audit-20260729.js` 已被 `data/.migrations.json` 熔断（实测重跑均跳过、数据零变动）。**不要删除标记重跑**。
3. **内容治理红线**：22 门阻断课程不得恢复跳转；`verified` 学术审定只能由项目所有者（文学院教师）人工完成；未知信息用 unknown/null，不得按声誉填空。HTTP 可达 ≠ 课程可信。
4. **上传物只有 dist/ 的 8 个文件**；正式部署用 `SITE_ORIGIN=https://域名/ node tools/build-site.js`（四联动重写 canonical/og:url/robots/sitemap，非法值构建即报错——均已实测）。
5. **CSP 纪律**：dist 的 script-src 纯 hash（两个内联脚本，build-site 自动计算并写入 meta 与 _headers，手工硬编码哈希会被立刻发现——接收方已独立复算一致）。`style-src 'unsafe-inline'` 是 6121 处内联 style 下的有意保留；frame-ancestors 只经 _headers 下发（meta 下发会被浏览器忽略并报 console error，击穿回归门禁）。
6. **浏览器回归抖动（已修复）**：交接文档遗留 #4 的两类假失败（CDP 事件超时、scrollNavVisible 过渡态采样）已由接收方于 2026-10-25 修复——事件等待超时重试一次（waiter 摘除防泄漏）、scrollNavVisible 返回后轮询 2s（只允许假→真翻转）。注意：带点击副作用的 evaluate 仍不重试（状态安全，有意设计）。
7. **audit-links --network 的 SSRF 残余**：初始 URL 有 scheme+公网校验，但 `redirect:"follow"` 保留——重定向跳内网风险已知并记录在案，是否收敛由接收方按威胁模型决定。
8. **git 分支**：`.github/workflows/ci.yml` 与 `links.yml` 的 push/PR 触发分支为 `main` 与 `master`（接收方已对齐）。推送 GitHub 时任一分支名均可触发；若另建分支需同步改 workflow。
9. **round2 第 20 项（接收方新增）**：「文档引用的命令存在」——README/交接文档/部署清单中出现的 `node tools/*.js` 与 `npm run *` 必须真实存在；改动文档或脚本名时会触发此门禁。

## 五、移交文档两处口径修正（接收方实测，v1.1 已勘误）

1. **「11 条不可达链接全部为 B 站 legacy av 号」不成立**：11 条不可达中仅 9 条是 av 号链接（hc-023/035/037/038/039/041/042/044/047），其余 2 条是 BV 号（hc-006 郦波·诗词名篇、hc-015 刘擎·西方现代思想）；而 av 号链接共 11 条，其中 hc-040（catalog_candidate/available）与 hc-046（blocked/content_mismatch）本次巡检均可达。「不可达∪av号∪已阻断」三个集合互相交叠但不重合；「均属已阻断课程」仅对不可达的 11 门成立。
2. **「18 个内联描边 SVG 图标」实为 21 个图标键**（另 JS 块 1978 行/98 函数，非 1883 行/93 函数）：`icon()` 表含 contrast/circle/dense/comfort 等后加图标。P0-1 门禁口径不受影响；命令侧一致性已由 round2 第 20 项落地，数字侧仍靠人工。

## 六、审计重点建议（火力分配）

- **已验充分、抽查即可**：30 处 innerHTML 渲染路径的转义防线、sanitizeCourses/sanitizePaths/sanitizePlanRaw 白名单、safeHttpUrl fail-closed、深链 decodeState 枚举白名单与关键词 50 字符/8 词上限、ics 的 CR/UID 清洗、hl() 正则缓存。
