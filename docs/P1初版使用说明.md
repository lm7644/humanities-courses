# 人文学科公开课策展：可用初版使用说明

## 本地试用

在项目目录运行：

```bash
npm run build:site
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

浏览器打开 `http://127.0.0.1:8765/`。

## 初版已经能做什么

- 浏览79门课程；1440×900电脑课程区默认一屏至少完整显示4门。
- 搜索课程名、讲师、摘要、分类、平台和学习标签；滚动后顶部课程控制台提供平台、难度、可访问、收藏、排序、检索和返回顶部。左侧点阵索引用于快速定位分类。
- 展开三条 4 周样板路线。
- 选择一条“当前路线”。
- 勾选节点完成状态，进度保存在当前浏览器的 `localStorage`。
- 点击路径中的课程引用，自动清除筛选并定位到课程卡。
- 默认课程卡采用高密度书目模式，点击“查看详情”展开完整编辑摘要和观点。
- 收藏、导入、导出和课程对比。
- 通过“首轮复核候选”查看六门核心候选课程。

## 重要边界

- 三条路线是待教师复核草案，不能替代正式教学方案。
- 来源身份与入口核查结果只保留在开发包的审核账本和验收报告中，不在课程卡展示。
- 学习进度只保存在当前设备和浏览器，不提供账号同步。
- 课程信息的唯一编辑源仍是 `data/courses.json`，路径唯一编辑源是 `data/paths.json`。

## 托管

上传 `dist/` 内全部文件，不要上传整个开发目录。该目录不含部署凭证、课程 JSON 编辑源、巡检工具和内部报告。

平台子域名可用于试用：

- GitHub Pages：`<owner>.github.io` 或 `<owner>.github.io/<repo>`。
- Cloudflare Pages：`<project>.pages.dev`。
- Netlify：`<site>.netlify.app`。

自有域名是可选项。它提供地址所有权和跨平台迁移能力，需要注册并按年续费；托管平台仍需另行选择。

复制为其他学科课程站时，按 `docs/项目复刻与可借鉴方案.md` 操作，并运行 `npm run test:replica`；不要直接复制历史发布目录。
