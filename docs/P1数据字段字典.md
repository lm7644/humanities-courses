# P1 数据字段字典

## 证据边界

- `link_checked_at`：说明URL在该日接受过来源/入口检查；检查方法见 `verification_method` 和审核账本。
- `verified_at`：只有教师或明确责任人完成事实、范围、访问条件、权利边界与教学适配复核后才填写。自动API和来源页面读取不得填写。
- `source_title`：平台接口或页面返回的原始标题，不等同于本站策展标题。
- `availability`：课程资料状态。`available`仅表示来源身份匹配且本次可作为入口；`needs_review`不得进入来源审核完成版；`content_mismatch`和`unavailable`必须阻断。
- `rights_basis=link_only`：本站仅提供外链和必要元数据，不表示获得内容转载授权。

## 编辑状态

- `core_candidate`：进入首轮 20 门核心候选库，仍需学科教师复核。
- `catalog_candidate`：保留在候选目录，暂不进入首发核心路径。
- `blocked`：已知不可用或内容错配，暂停跳转。
- `verified`：完成事实、访问、版权边界、学术适配与编辑判断复核后方可使用。

## 未知值原则

无法证明的信息统一使用 `unknown`、`null` 或空数组；禁止根据平台、学校名、讲师声誉推断字幕、免费范围、授权、课程质量或完成时间。

## 路径状态

三条样板路径当前均为 `draft_requires_academic_review`。所有课程节点标记 `pending_lesson_index`，表示尚需教师把推荐范围精确到讲次；不得把草案显示成已发布课程方案。
