# P1.5 课程题签与精简计划验收记录

日期：2026-07-30

## 目标

1. 删除不符合当前阶段或价值过低的外部参考对象。
2. 强化课程模块中教师名与课程名的视觉识别。
3. 不在公开网页展示“入口已核/来源已核”等后台治理标签。
4. 保持1440×900课程区一屏至少完整显示4门。

## 计划删减

活动账本由20项缩减为12项。

### 保留

- 方法参考：OSSU、CS自学指南、Hocbigg Literature、Hocbigg Philosophy、Open Learning Paths。
- 聚合参考：Class Central、Open Culture。
- 开放资源候选：OER Commons、MIT OpenCourseWare、Open Yale Courses、Stanford Encyclopedia of Philosophy、OpenStax。

### 删除

- Collecobrary：图谱需求未成立，当前增加复杂度而不产生直接价值。
- MOOC Search：语义检索尚无用户问题证据，技术方向超前。
- Patth、Pathio、Ornix、Learnbase：只有竞品观察价值，不形成当前开发任务。
- 清华大学图书馆开放课程系统：入口不稳定，无法支持当前可验证落点。
- 网易公开课：属于普通课程来源平台，不是需要复刻的项目；具体课程继续逐门审核。

`tools/validate-project.js` 强制要求12项全部存在，并禁止8个已删除对象重新进入活动账本。

## 课程题签设计

横幅升级为“课程题签”：

- 左侧6px分类色脊；
- 分类名作为顶部小型索引；
- “主讲”色签＋16px教师名；
- 28px衬线粗体课程名，最多两行；若原始名称以教师名开头，视觉题签自动去掉重复署名前缀，源数据和检索仍保留原名；
- 更深的左侧遮罩保证文字对比；
- 不显示来源、核验、开放状态徽标。

来源身份与入口核查结果只保留在 `data/source-audit-20260729.json` 与验收报告中。内容错配或不可用课程仍通过禁用跳转保证安全，页面统一显示“暂无可用链接”，不暴露后台审核术语。

## 验收门禁

- 79门题签全部匹配分类、教师和课程名；
- 题签中的教师字号至少15px，课程名至少26px；
- 网页可见区域中“入口已核/来源已核/内容错配”等治理标签数量为0；
- 默认卡片最高不超过390px；
- 1440×900一屏完整显示至少4门；
- 顶部7项课程控制台与主工具区双向同步；
- 390px移动端无横向溢出，操作目标至少44px；
- HTTP、`file://`运行错误0；
- 12项外部参考账本、空目录复刻与ZIP解包复验全部通过。
