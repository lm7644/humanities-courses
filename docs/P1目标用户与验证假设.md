# P1 目标用户与验证假设

## 首要用户假设

有一定阅读能力、希望系统补充人文学科基础的大学生。

核心任务：在 3 分钟内找到一条与当前问题、基础和可用时间匹配的路线，并开始第一个学习节点。

成功行为：选择路径、查看推荐理由、进入课程或原典节点、完成第一项证据任务，并在 7 日内返回。

## 次要用户假设

高校青年教师。

核心任务：寻找可核验的公开课程、原典和课堂任务，判断其能否进入教学设计。

成功行为：查看来源与局限、提交纠错、复核一条课程或路径节点。

## 明确排除

首轮不以零基础泛娱乐用户、证书导向学习者、付费课程消费者或专业研究者为主要对象。该边界需通过访谈与四周行为数据验证，当前仍是假设。
