## 一、项目背景与目标

### 1.1 背景

本项目服务于汉语言文学专业本科生的公开课选课与学习规划场景。网络平台上的优质人文学科公开课分散于 B 站、中国大学 MOOC、edX、学堂在线等平台，访问条件（免费/付费/需登录）不一，学生自行检索成本高、试错成本高。本项目以「策展」形态将课程按学科分类集中呈现，配以样板学习路径与个人学习规划工具。

### 1.2 目标与定位

- **对学习者**：一站浏览 205 门经初步核验的人文学科公开课，按平台、访问条件、难度筛选；记录笔记、打卡、生成日历提醒。
- **对教师**：提供可共建的内容治理框架——每门课程带来源证据字段，未经学术审定的内容明确标注，不把「链接可访问」冒充「课程可信」。
- **形态约束**：纯静态站点，双击 `index.html` 即可运行（`file:// 协议），可整体打包转发，无需服务器与构建环境。

### 1.3 当前状态（移交时点）

- 课程 205 门；其中 183 门提供可跳转外部入口，22 门因失效、错配或证据不足处于阻断状态（页面明示，不跳转；其中 5 门已找到同课替代入口并双向互链，6 门经 2026-10-27 联网复检维持阻断并记录证据）。
- 学习路径 5 条，全部为 `draft_requires_academic_review`（草案，待教师精确到讲次）。
- 核心候选 20 门（首轮人工复核范围）；来源审核账本 41 门；外部参考对象账本 12 项。
- **教师学术审定完成数：0**——这是项目当前最重要的人文质量缺口，技术手段不能替代。
- 联网巡检最近一次结果：192 可达 / 11 不可达（其中 9 条为 B 站 legacy `av` 号链接、2 条为 `BV` 号链接，均属已阻断课程）/ 2 无法判定 / 0 标题漂移 / 可访问课程失效 0 / 过期 0。

## 二、系统架构与技术栈

### 2.1 总体形态

纯静态站点，**无后端、无数据库、无用户认证、无 npm 第三方依赖**。运行时唯一的持久化是浏览器本机 localStorage。全部「工程能力」由 Node 22 脚本在开发期提供（构建与校验），不进入线上。

### 2.2 数据管线（单向流）

```
data/courses.json（205门，唯一编辑源）  data/paths.json（5条，唯一编辑源）
        │                                        │
        │ tools/build-data-script.js（--check 字节级漂移比对）
        ▼                                        ▼
data/courses.js + data/paths.js（window 全局变量，支持 file://）
        │  <script src> 加载
        ▼
index.html（单文件应用：994行CSS + 1978行JS/98函数 + 21个内联描边SVG图标键）
        │  tools/build-site.js（先跑3道校验，再全量重建 dist/；
        │   注入JSON-LD/noscript/sitemap/robots，生成_headers/_redirects，
        │   计算内联脚本sha256写入CSP；SITE_ORIGIN可覆盖站点基址）
        ▼
dist/（平台无关静态产物，8个文件）
        │  tools/build-release.js（白名单复制 + 禁止项与令牌终扫）
        ▼
release/humanities-courses-p1/（完整交付包，63个文件）
```

### 2.3 技术栈清单

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | 原生 HTML/CSS/JS 单文件 | 无框架、无打包器；约束来自 `file://` 直开与单文件转发需求 |
| 数据 | JSON → JS 全局变量 | 确定性 stringify 代码生成；`--check` 模式做字节级漂移检测 |
| 工具链 | Node.js ≥22 内置模块 | 14 个脚本，零 npm 依赖（fs/path/crypto/child_process/http/net/url） |
| 校验 | 自研门禁链 | Schema（自研 mini 校验器）+ 业务规则 + WCAG 对比度 + 符号字形 + 账本闭合 + 离线/联网巡检 |
| 浏览器验收 | 自研 CDP 客户端 | `tools/browser-smoke.mjs` 驱动真实 Chrome 回归（无 Puppeteer 依赖） |
| CI | GitHub Actions | `links.yml`（周度死链+外链巡检）+ `ci.yml`（push/PR 跑 npm test）；6 个 action 全部 SHA pinning |
| 部署 | 任意静态托管 | 历史部署于 CloudBase 测试域名；移交后迁往委托人新申请的服务器（待定） |

## 三、核心功能模块说明

| 模块 | 功能 | 关键实现 |
|---|---|---|
| 课程展示 | 205 门课程卡（封面/题签/难度/讲师/摘要/观点），分类分组与侧边点阵导航 | 程序化 SVG 封面（噪声滤镜全站共享单实例，零请求零版权）；`wrapCN` 标题换行 |
| 筛选 | 平台多选（并集）+ 访问条件（免费/付费/需登录/待确认）+ 难度/技法/排序 + 只看可跳转/收藏/已学 | 状态写入地址栏深链 `#f=plat=B站,edX&acc=free`，旧版单平台链接兼容；空结果回显生效条件并提供清除入口 |
| 检索 | 多词 AND + 相关度排序 + 拼音模糊（音近归一/首字母/编辑距离≤1）+ 命中高亮 | 关键词上限 50 字符/8 词（深链与输入同源，防 DoS）；`hl()` 正则去重缓存 |
| 学习规划 | 笔记、当日打卡、近 26 周热力图、统计卡、导出/导入 JSON、`.ics` 周提醒（每周 20:00 共 8 次） | 仅写本机 localStorage（`hm-plan`/`hm-study`），不上传不同步；导入按更新时间合并并清理已下架课程残留；直载与导入共用 `sanitizePlanRaw` 校验 |
| 学习路径 | 5 条草案路径展示、展开、进度追踪 | 全部标注「草案·待复核」 |
| 对比 | 最多 3 门课程字段对比弹窗 | 会话内临时选择 |
| 收藏迁移 | 旧版 `hm-favs`（数组/URL 形式）自动迁移为稳定课程 ID | `migrateFavoriteRefs()`，未解析 URL 保留待查 |
| 分享 | 复制当前页面链接，剥离全部查询参数与片段 | `shareBtn` 处理；浏览器回归含 token 金丝雀断言 |
| 数据加载降级 | `data/*.js` 缺失或格式错时显示友好错误指引 | `showLoadError()` |

**运行时数据防线**（2026-10 修复集新增）：课程数据视为半可信输入，`start()` 启动时执行 `sanitizeCourses/sanitizePaths`——枚举字段白名单归一、字符串长度上限（2000 字符）、数值类型检查、外链 URL scheme 白名单（`safeHttpUrl`，仅 http/https）；非法值回落安全默认值并 console 告警。

### 4.3 部署配置要点

- **上传物只有 `dist/` 8 个文件**（index.html、data/ 两个 JS、_headers、_redirects、robots.txt、sitemap.xml、.nojekyll），不要把开发目录传到站点根。
- **`SITE_ORIGIN=https://正式域名/ node tools/build-site.js`**：构建期重写 canonical、og:url、robots 的 Sitemap 行与 sitemap.xml 全部 loc。不设置则沿用 index.html 内的 canonical（当前为历史测试域名，上线前必须处理）。
- `_headers`（Netlify/Cloudflare 约定）承载 CSP 等安全头；平台不解析时 meta CSP（script-src 纯 hash）仍然生效，但建议服务端补配并记录唯一配置源。
- `_redirects` 在 hash 路由下冗余，可删；`.nojekyll` 仅 GitHub Pages 需要。
- 必须启用 https（CSP、剪贴板 API 均要求安全上下文）。
- 详见 `docs/部署前准备清单.md`。

### 4.4 CI 状态

- `ci.yml`：push/PR 触发 `npm test`（7 条零网络门禁）。**仓库推送到 GitHub 后才生效**——移交时该目录已是 git 仓库（首次提交 b6d9b50），但尚未添加远端。

## 五、第三方依赖与接口说明

### 5.1 依赖状况

- **npm 依赖：零**。`package.json` 无 dependencies 字段、无 node_modules、无 lock 文件；tools/ 仅用 Node 内置模块。供应链面极小。
- **浏览器接口**：localStorage、Clipboard API、Blob/URL.createObjectURL（导出/ics）、WebSocket+CDP（仅开发期浏览器验收，经 Node 内置 WebSocket）。
- **GitHub Actions 第三方 action**（全部 40 位 SHA pinning，dependabot 周更）：actions/checkout v4.2.2、actions/cache v4.2.3、actions/setup-node v4.4.0、lycheeverse/lychee-action v2.9.0、peter-evans/create-issue-from-file v5.0.1、actions/upload-artifact v4.6.2。

### 5.2 外部数据接口

- **B 站开放 API**（`api.bilibili.com/x/web-interface/view`）：仅 `audit-links.js --network` 巡检时调用，核验视频存在性与来源标题漂移；15s 超时 + 只读前 2048 字节。
- **课程外链 205 条**：指向各平台课程页（B 站/中国大学MOOC/edX/学堂在线/智慧高教/喜马拉雅等）。HTTP 可达仅代表链接有效，课程名、讲师、免费范围、授权与内容匹配仍需人工确认（这是项目既定的证据边界，自动化不能替代）。
- 联网巡检已内置 SSRF 控制（仅 http/https、内网/回环/链路本地黑名单）；`redirect:"follow"` 的重定向跳内网残余风险已知会记录在案。

## 七、安全与合规注意事项

### 7.1 已实施的安全防线（均经实测）

- **输出转义**：30 处 innerHTML 赋值点全量梳理，文本/属性一律 `escapeHTML()`；渲染前对半可信数据执行枚举白名单、长度上限、URL scheme 校验。
- **CSP**：dist 产物 script-src 纯 hash（两个内联脚本），meta 与 _headers 一致；frame-ancestors 仅经 _headers 下发（meta 下发会被浏览器忽略并记 console error）。
- **输入上限**：深链关键词 50 字符/8 词；localStorage 直载与导入共用 sanitizePlanRaw（类型/日期/长度/危险键）。
- **构建安全**：execFileSync 全部数组参数无注入；白名单复制无路径穿越；发布包禁止项（.edgeone/.env*/auth.json/*.pem/*.key/id_rsa/.netrc/.npmrc）+ 令牌正则（含反引号/模板字面量形态）+ 源码树扫描。
- **SSRF**：联网巡检仅公网 http/https。
- **凭据纪律**：本包无任何存活凭据（已专项扫描）；部署令牌只进平台/CI Secret。

### 7.2 数据隐私

站点无账户体系；学习数据（笔记/打卡/热力图）仅写本机浏览器 localStorage，不上传、不跨设备同步；导出文件由使用者自管。无隐私采集面。

### 7.3 内容合规与许可边界

- **证据边界（项目核心治理原则，须维持）**：HTTP 可达不等于课程可信；未知信息用 `unknown`/`null`/空数组，不以平台或讲师声誉推断；22 门阻断课程在页面明示「暂无可用链接」及其原因。
- **许可边界**：`reference-adoption.json` 账本记录 12 个外部参考对象的纳入/许可阻断决定；5 项许可阻断资源不得进入课程与路径正文（audit-plan-alignment 门禁把关）。课程外链授权 basis 全部为 `link_only`——只做链接策展，不转载内容。
- **封面版权**：全部课程封面为程序化生成 SVG（零外部请求、零版权素材）。
- **图标规范**：P0-1 门禁——禁用 emoji 作功能图标，全站统一描边 SVG 图标 21 个（`icon()` 表口径，含 3 个难度档位与 4 个开关图标）；改动页面时须保持。
