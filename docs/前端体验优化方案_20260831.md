# 前端体验优化方案（2026-08-31 评估）

> 评估对象：本项目仓库目录（人文学科公开课目录）
> 评估方式：项目内视觉基线核对 + 设计资源/最佳实践对标（基于项目风格与记忆中用户审美偏好）
> 优先级原则：低风险 / 高收益 / 可逆；避免引入新依赖；保持 file:// 单文件直开
> 当前基线：八门禁全绿 / P0-1 emoji 扫描 0 命中 / 130 门课 5 路径 / 朱红主题双主题切换 / 描边 SVG 图标 / 程序化 SVG 封面

## 二、优化项（按收益与风险排序）

### 优先级 A：视觉克制与气质提升（投入小、风险低、立即可见）

#### A1. 卡片封面色相体系扩展（估 1–2h）

| 项 | 内容 |
|---|---|
| 现状 | 16 类分类各有色，CAT_COLORS 集中定义；视觉效果"花但克制" |
| 优化 | 把 16 色按色相排序并验证 WCAG AA 对比；过暗或过亮类别微调（±5–8） |
| 预期 | 卡片墙更"画廊"感，避免色相打架 |
| 风险 | 低；改 token 即可 |
| 建议操作 | 直接调整 `index.html` CSS 顶部 `--cat-color` 与封面 SVG 内填色 |

#### A2. 题签字号与字重节奏（估 1h）

| 项 | 内容 |
|---|---|
| 现状 | 标题 28px / 教师 16px / 分类 10.5px；三档电平条已是 SVG |
| 优化 | 教师字号 16→17，字重 800→850；分类字号加 0.5pt letter-spacing；行高 1.2→1.15（更紧） |
| 预期 | 题签"沉下去"，更像学术海报；不破坏 390px 高度门禁 |
| 风险 | 极低；只动 token |

#### A3. Banner 装饰条弱化（估 0.5h）

| 项 | 内容 |
|---|---|
| 现状 | 6px 主题色竖条 + 16px 发光阴影 `color-mix(.55)` |
| 优化 | 竖条 6→4px，阴影 opacity .55→.35；保留"识别度"，去掉"装饰过重" |
| 预期 | 学术感更强，不刺眼 |
| 风险 | 低 |

### 优先级 B：交互质感与微动效（估 4–8h）

#### B1. 详情区"展开/收起"过渡（估 1h）

| 项 | 内容 |
|---|---|
| 现状 | `.card-detail{display:none}` 直接显隐 |
| 优化 | 用 `max-height` + `opacity` + `transition`（200ms）；使用 `prefers-reduced-motion` 兜底 |
| 预期 | 展开更"自然"，克制不夸张 |
| 风险 | 低 |

#### B2. 同课关联角标入场动画（估 1h）

| 项 | 内容 |
|---|---|
| 现状 | `.alt-badge` 直接显示 |
| 优化 | 渲染时按课程 ID 错峰 30–60ms 淡入；`will-change` 配合 `contain` |
| 预期 | 130 门卡片加载时"涟漪感"，有节奏不抢戏 |
| 风险 | 低；注意动效开关时跳过 |

#### B3. 同课跳转动画（估 1h）

| 项 | 内容 |
|---|---|
| 现状 | 点击 `.alt-jump` → `focusCourseFromPath` → 滚到目标卡 |
| 优化 | 平滑滚动已用 `behavior:smooth`；加 3 步：① 当前卡虚化 ② 路径提示线（SVG）③ 目标卡"呼吸一次"（180ms） |
| 预期 | 跳转上下文清晰，用户不迷路 |
| 风险 | 中；路径提示线需 SVG 测量，要测不同位置 |

#### B4. 卡片 hover 反馈克制化（估 1h）

| 项 | 内容 |
|---|---|
| 现状 | 3D tilt + 阴影 + 分类条发光 |
| 优化 | tilt 角从 ±14° 降到 ±8°；阴影层级从 3 级简化为 2 级 |
| 预期 | "翻动"感保留但不夸张；移动端无 hover 无影响 |
| 风险 | 低 |

### 优先级 C：内容呈现深化（估 6–12h）

#### C1. 「暂停原因」可视化（估 2h）

| 项 | 内容 |
|---|---|
| 现状 | `.blocked-note` 用列表项，措辞经 `stripGovPhrases` 处理 |
| 优化 | 顶部加 8px 高"红色指示条"；文末加"其他平台入口"占位（待 alt 跳转补全）；用 SVG icon 替换前缀 |
| 预期 | 22 门阻断课程一眼可辨"这是被审查的，不是死的" |
| 风险 | 低 |

#### C2. 学习路径进度可视化（估 4h）

| 项 | 内容 |
|---|---|
| 现状 | 节点勾选布尔 + 进度百分比 |
| 优化 | 路径条按周横向布局；当前周加朱红高亮；已完成节点用描边 SVG 对勾；未做加空心圆 |
| 预期 | 一眼看到"走到第几周了"；移动端用纵向时间线降级 |
| 风险 | 中；SVG 测量与降级都要测 |

#### C3. 教师视角筛选（估 1h）

| 项 | 内容 |
|---|---|
| 现状 | 无 |
| 优化 | 顶部导航加"按教师浏览"，点击进 `?teacher=叶嘉莹` 直接定位；不增深链维度，复用 `state.keyword` |
| 预期 | 收藏同一教师多门课的用户能快速聚合 |
| 风险 | 低；复用现有搜索 |

#### C4. 「已学」徽标（估 2h）

| 项 | 内容 |
|---|---|
| 现状 | `hm-study` 仅有布尔；卡片无视觉区分 |
| 优化 | 已学课程题签加 6px 朱红对勾 SVG（不抢字）；筛选条加"只看过"；和收藏互相独立 |
| 预期 | 130 门里已学多少一目了然；与 P5 学习规划衔接 |
| 风险 | 低；与 study-btn 互不冲突 |

### 优先级 D：性能与扩展（估 3–6h，按需）

#### D1. feTurbulence 缓存（估 1h）

| 项 | 内容 |
|---|---|
| 现状 | 130 个 SVG 内嵌 `<filter id>`，每个含 `feTurbulence` |
| 优化 | 改为全局 `<defs>` 单实例 + `<use href="#filter">`；内存与首屏渲染都降 |
| 预期 | 渲染 -10–15%（视浏览器）；不影响视觉 |
| 风险 | 低；要浏览器实测 diff |

#### D2. attachTilt 监听节制（估 2h）

| 项 | 内容 |
|---|---|
| 现状 | 每卡挂 `mousemove` 监听，130 个常驻 |
| 优化 | 改用 IntersectionObserver：仅视口内 + 悬停时才挂监听；`mouseleave` 立即卸 |
| 预期 | 监听器峰值从 130 降到 8–12 |
| 风险 | 中；要回归 hover 体验 |

#### D3. 130→300 门扩容路线（估 2h）

| 项 | 内容 |
|---|---|
| 现状 | 130 门全量渲染，无虚拟滚动 |
| 优化 | 当课程数 > 200 时启用"懒渲染：先渲 60，进入视口追加"；保留全量分组但单帧 DOM 上限可控 |
| 预期 | 300 门规模仍稳定；当前不动（按设计约定 >200 才启） |
| 风险 | 中；首次写要充分测 |

### 优先级 E：内容与运营（估 1–2h，非代码）

| # | 项 |
|---|---|
| E1 | README 增加"视觉风格说明"小节（封面色板、字体栈、字号节奏），便于复刻与交接 |
| E2 | docs/ 下补 `visual-spec.md`：色值 / 字号 / 间距 / 阴影层 / 动效时序，规范化的"视觉令牌" |
| E3 | `data/templates/` 下补 `cover.example.json` 与 `card.example.json` 给后续教师扩展用 |

## 三、不做（明确放弃）

| 项 | 原因 |
|---|---|
| 引入 Tailwind / shadcn | 破坏单文件 + 零运行依赖原则 |
| 替换 SVG 封面为真实图片 | 走版权审视、增加网络请求；程序化 SVG 已很好 |
| 深色 → 浅色渐变背景 | 违反 P0-2 朱红定调；浅色背景足够干净 |
| 加 3D 鼠标视差、粒子效果、AI 渐变光晕 | 违反模板化审美；学术气质优先 |
| 重新设计 logo / 字体 | 当前已克制稳定，无收益 |
