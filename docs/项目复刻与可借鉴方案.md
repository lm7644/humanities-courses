# 人文学科公开课项目：复刻与可借鉴方案

日期：2026-07-29  
适用版本：P1.5 课程题签与精简复刻计划版

## 1. 结论

本项目已形成可复刻的静态课程策展底座。复刻者无需 EdgeOne、数据库或前端框架，只需替换课程与路径 JSON，即可生成新的课程策展站。

“可复刻”由实际构建演练证明，不以文档声明代替。每次发布必须在空临时目录复制白名单工程文件，重新生成数据、构建 `dist/` 并通过浏览器回归。

## 2. 单一数据源与复刻入口

| 资产 | 作用 | 是否编辑源 |
|---|---|---|
| `data/courses.json` | 课程、来源、访问、证据与局限 | 是 |
| `data/paths.json` | 学习路径与节点 | 是 |
| `data/course.schema.json` | 课程数据契约 | 否，规则源 |
| `data/path.schema.json` | 路径数据契约 | 否，规则源 |
| `data/source-audit-20260729.json` | 逐门来源审核账本 | 否，审计证据 |
| `data/reference-adoption.json` | 外部对象纳入、后置、阻断与排除账本 | 是，计划审计源 |

## 3. 从零复刻步骤

1. 复制工程白名单，不复制 `.edgeone/`、`.env`、历史发布包、缓存或旧验证截图。
2. 以 `data/templates/course.example.json` 为字段参考，建立新的 `courses.json`；ID必须稳定且唯一。
3. 以 `data/templates/path.example.json` 为参考建立 `paths.json`；课程节点只能引用存在且未阻断的核心候选。
4. 未确认事实写 `unknown`、`null` 或空数组；不能根据名师、名校或页面可达性补造。
5. 运行：

```bash
npm run build:data
npm run build:core
npm run verify
npm run build:site
npm run verify:site
npm run test:replica
```

6. 只上传 `dist/`。公开部署平台、账号和域名由项目所有者选择并授权。

## 4. 来源审核复刻协议

逐门审核必须分别记录：

1. 来源身份：实际标题、发布者/机构、规模和课程名是否匹配。
2. 入口状态：本次是否可访问，是否付费、登录或只可试听。
3. 证据边界：来源核查不等于教师学术审定，不证明转载授权和长期可用。

结论只有三类：

- `available`：身份匹配，入口本次可作为来源链接。
- `content_mismatch`：链接与策展名/规模不符，必须 `blocked`。
- `unavailable`：无法取得可确认入口，必须 `blocked`。

严禁为了清零待核项，把无法确认的课程硬改成 `available`。

## 5. 外部对象的纳入方式

活动计划只保留与当前产品方向直接相关的12个外部参考对象。完整机器可读账本为 `data/reference-adoption.json`，Schema 为 `data/reference-adoption.schema.json`；验证器强制检查保留对象具备开发阶段、工程落点、验收标准、复用边界和当前状态，同时禁止8个已删除低价值对象重新进入计划。

| 分类 | 外部对象 | 纳入方式 | 阶段与工程落点 | 验收与状态 |
|---|---|---|---|---|
| 方法参考 | OSSU、CS自学指南 | 只借鉴先修顺序、核心/进阶、中文维护与纠错思想 | P1治理、P2路径；`courses.json`、`paths.json`、治理规则、验证器 | 已落工程；内容仍待教师审定 |
| 方法参考 | Hocbigg Literature、Hocbigg Philosophy | 只借鉴课程＋原典＋练习＋成果结构 | P2；`paths.json` | 已落路径结构；两项目分开记录 |
| 方法参考 | Open Learning Paths | 只借鉴开放路径数据表达 | P2；`paths.json`、路径UI、本地进度 | 已运行并有浏览器门禁 |
| 聚合参考 | Class Central、Open Culture | 独立核验元数据、外链与免费范围说明 | P1；课程来源、访问方式、最后核验日期 | 已纳入数据模型；不复制页面、清单、评价或品牌资产 |
| 开放资源 | OER Commons | 权利、材料、证书字段及候选资源 | P3试点候选 | 具体资源未逐项核证前保持许可证阻断 |
| 一手资源 | MIT OpenCourseWare、Open Yale Courses、SEP、OpenStax | 待接入资源候选 | P3；未来按路径逐项接入 | 当前均阻断于许可证/条款审查，不整体导入，不宣称已提供 |

已从活动开发计划删除：Collecobrary、MOOC Search、Patth、Pathio、Ornix、Learnbase、清华大学图书馆开放课程系统、网易公开课。删除理由分别为需求未成立、技术方向喧宾夺主、只具竞品观察价值、入口不可稳定复核，或属于普通来源平台而非待复刻项目。历史研究信源可保留用于解释决策，不再形成开发任务。

### 5.1 外部对象最低记录字段

每条账本记录必须包含：对象类型、纳入模式、开发阶段、工程落点、验收标准、许可证或条款来源、复用边界、状态、触发条件、证据URL、核验日期和责任角色。后置、排除或许可证阻断对象必须有触发条件。

### 5.2 复制与许可证边界

- 当前实现未复制上述开源项目的代码、数据文件、README文本、图标、截图或界面资产；只借鉴可抽象的方法。
- 若未来复制任何代码或资产，必须先记录许可证名称、再分发条件、署名要求和第三方依赖，并另立验收。
- 外部课程平台原则上只保存外链与本项目独立核验的元数据，不镜像视频、音频、字幕、讲义或教师肖像。
- OER、MIT、Yale、SEP、OpenStax须按具体资源分别核验，机构整体“开放”不能替代单项授权证明。
- 微信 `web-view`、业务域名等属于部署平台约束，不属于可复刻项目，单独在部署方案中管理。

## 6. 与原开发方案的一致性

当前已实现：

- P0安全止血的本地部分：公开产物白名单、凭证门禁、无EdgeOne依赖。
- P1数据可信化底座：稳定ID、Schema、来源字段、41门剩余待核来源全覆盖账本、错配/不可用阻断。
- P2样板路径的工程原型：三条4周路径、节点进度、课程定位。

仍未实现，且不得提前宣称完成：

- 20门核心课程的教师二次学术复核。
- 三条路径精确到讲次、原典版本并通过至少2名相关教师审定。
- 15至24人、至少4周的真实试用及留存/任务指标。
- PWA、账号同步、AI推荐、教师后台和小程序。

## 7. 复刻验收门槛

- 数据：唯一ID、唯一URL、Schema与业务门禁全部通过。
- 审核：没有 `availability=needs_review`；无法确认者已阻断。
- 视觉：1440×900课程区一屏至少完整显示4门；默认卡片最高≤390px、最小宽度≥560px；79门题签均呈现分类、教师和课程名，不显示“入口已核/来源已核”等治理状态；教师字≥15px、课程名≥26px；程序化背景文字重叠数为0；Hero高度≤330px；滚动后顶部7项课程控制台可见且与主工具区同步；左侧浮动索引不侵占主列；移动端无横向溢出。
- 运行：HTTP、`file://`、桌面、移动端无运行时错误。
- 安全：公开产物和复刻副本不含 `.edgeone/`、`.env`、`auth.json` 或部署Token。
- 外部对象：12个高价值对象进入机器账本；8个低价值对象由验证器禁止重新进入活动计划；一手资源未完成许可核证时不能进入路径正文。
- 交付：只上传 `dist/`；开发包与公开站点包明确分离。
